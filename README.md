# Graveyard Smash 3D (web build)

A Halloween platform fighter: twenty-five monsters knocking each other off
haunted stages. Versus for 1-4 on one screen, the Classic trail, Haunted
Events, Bonus courses, Training, and online rooms. Made in Godot 4.6.

This repo holds only the browser build, served by GitHub Pages at
https://perhapsjohn.github.io/GraveyardSmash3D/ (it is also a cart in the
Wayside Station arcade). Phones load `index.mobile.pck`, desktops `index.pck`.
`?room=CODE` opens the game straight into a friend's online room.

The source lives elsewhere; this is regenerated by the game's `tools/publish_web.sh`.
